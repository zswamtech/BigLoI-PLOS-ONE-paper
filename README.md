# BigLoI PLOS ONE paper repository

This directory is the article-specific reproducibility package for the BigLoI manuscript prepared for PLOS ONE.

It is designed to separate the minimal paper package from the broader project monorepo.

## Structure

- manuscript/: submission-ready manuscript and cover letter files.
- figures/: final figure assets for editorial submission.
- data/: minimal derived datasets, metadata, and figure/table source files.
- code/: minimal scripts and environment notes required to reproduce the article outputs.
- statements/: final text blocks for journal metadata and compliance statements.

## Intended public release

Before submission, this package should be mirrored to a dedicated public repository or archived release and linked to a persistent identifier such as a Zenodo DOI.

See PUBLISHING_EXTERNAL.md for the recommended publication path and the staging workflow for a standalone public package.

## Minimum contents expected before release

- final manuscript in Markdown and DOCX;
- final cover letter in Markdown and DOCX;
- Fig1.tif to Fig6.tif;
- figure source data tables as CSV;
- table source data as CSV;
- data dictionary for derived files;
- scripts or commands needed to regenerate article figures and summary outputs;
- data availability and code availability statements.
