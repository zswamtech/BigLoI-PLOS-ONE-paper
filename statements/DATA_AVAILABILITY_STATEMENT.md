# Data availability statement

All data necessary to reproduce the findings are available from public administrative sources and from the article-specific reproducibility archive. Public source data were obtained from SECOP-II, INVIMA, and SISMED through their open-access endpoints. The processed minimal dataset underlying the reported figures, tables, and statistical summaries, together with data dictionaries and provenance notes, is provided in the article-specific repository package available at <https://github.com/zswamtech/BigLoI-PLOS-ONE-paper>.
