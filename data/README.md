# Data package

This folder is reserved for the minimal derived dataset required to reproduce the findings reported in the manuscript.

It should not attempt to mirror all third-party source data.

Recommended contents:

- derived/figures/: CSV or TSV files underlying each figure.
- derived/tables/: CSV or TSV files underlying each manuscript table.
- derived/metadata/: data dictionary, provenance notes, and field definitions.

Public third-party source data should be referenced, not duplicated, unless redistribution is clearly allowed and necessary.
