# External public sources

The manuscript relies on public administrative data obtained from third-party open-access sources.

## Core sources

- SECOP-II open data via datos.gov.co
- INVIMA open administrative records
- SISMED reference price data

## Repository strategy

This package should include only the minimal processed dataset necessary to reproduce the published results.

The full raw source universe should be referenced through source URLs, access notes, extraction dates, and provenance metadata.
